# Fourier Transform Visualizer

Une application web interactive pour visualiser et analyser les transformations de Fourier.

## Fonctionnalités

- **Entrées multiples** : Audio (fichiers, microphone), signaux générés, images
- **Analyse FFT** : Calcul rapide de la transformée de Fourier
- **Visualisations** : Graphiques du domaine temporel et fréquentiel
- **Fenêtrage** : Options Hann, Hamming, Rectangulaire pour réduire les artefacts
- **Échelles flexibles** : Affichage linéaire et logarithmique

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Ouvre http://localhost:5173 pour voir l'application.

## Build

```bash
npm run build
```

## Technologie

- React 18
- TypeScript
